# ORQ – AI Agent Control Plane

ORQ is an open-source AI Agent Control Plane designed to manage, orchestrate, and monitor AI agents across multiple providers.

## ✨ Features

- FastAPI backend
- React + Vite dashboard
- PostgreSQL database
- Redis caching
- Docker Compose development environment
- JWT Authentication (planned)
- Multi-provider AI support (planned)
- Agent orchestration (planned)
- Observability & analytics (planned)

## 🏗️ Tech Stack

### Backend
- FastAPI
- SQLAlchemy
- Alembic
- PostgreSQL
- Redis

### Frontend
- React
- Vite
- TypeScript

### DevOps
- Docker
- Docker Compose

## 🚀 Getting Started

### Clone

```bash
git clone https://github.com/tylrx404/ORQ.git
cd ORQ
```

### Start

```bash
docker compose up --build
```

Backend:

```
http://localhost:8000
```

Swagger UI:

```
http://localhost:8000/docs
```

Frontend:

```
http://localhost:5173
```
